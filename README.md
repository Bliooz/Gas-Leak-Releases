# Gas Leak v1.6.0
**Minecraft:** 1.21.1  **Loader:** NeoForge (21.1+)  Client only

## What's new in v1.6.0
### HUD
- **SessionStats** – playtime, distance travelled, deaths and blocks mined
- **ArmorHUD** – armour and held items with durability, warns before anything breaks
- **PotionTimers** – active effects with countdowns, can hide the vanilla icons
- **ServerInfo** – TPS, player count, ping and time connected
- All HUD panels now stack neatly in any corner

### Utility
- **SoundAlerts** – sound when your health is low or someone joins
- **Crosshair** – custom shape, colour, size, gap and thickness
- **Tooltips** – shulker box previews and exact durability numbers
- **Freelook** – hold a key to look around without turning
- **TabList** – ping as numbers and friends highlighted

### Whitelisted servers only
- **StorageESP**, **Nametags**, **ElytraFly**, **NoSlow**

### Menu
- Rename and recolour waypoints
- Keybind overview with clash warnings
- Start typing anywhere to search
- Smoother open and page animations

## Install
1. Install **NeoForge for Minecraft 1.21.1**
2. Put `GasLeak-1.6.0.jar` in your `mods` folder
3. Launch game & load into a server, press **Right Shift** in a world and enter your access key (CONTACT: @DevBliooz to inquire about a key)
4. Add your server in the **Servers** tab to unlock everything there
